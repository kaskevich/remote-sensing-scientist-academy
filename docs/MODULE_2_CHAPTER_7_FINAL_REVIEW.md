# Module 2 Chapter 7 final review

Review date: 11 August 2026

## Scope

Chapter 7 publishes three complete lessons and one practicum:

- 2.35 SQL for Geospatial Scientists;
- 2.36 PostGIS Fundamentals;
- 2.37 Managing Large Spatial Data;
- Chapter 7 Practicum — Build a Governed Spatial Database Handover.

## Vertical quality

Every lesson defines one central concept, begins with the scientific population or relationship, uses synthetic Baltic coastal meadow training evidence, includes a compact worked example, explains every line, makes learners predict before execution, treats failure modes explicitly and ends with a portfolio component.

The chapter does not treat databases as an IT detour. SQL is taught as population definition, PostGIS as preserved spatial semantics at shared scale and architecture as protection of authority, lineage and recovery.

## Horizontal curriculum integrity

The chapter reuses prior competencies deliberately:

- Module 1 table grain, missingness and reproducibility become SQL query contracts;
- Chapters 1–2 CRS, predicates, joins and topology become PostGIS validation rules;
- Chapters 3–5 immutable raster/UAV/satellite inputs become governed object classes;
- Chapter 6 sampling and analytical-population discipline becomes relational inclusion evidence.

It prepares Chapter 8 by distinguishing transactional vector records, columnar analytical copies and immutable object storage before multidimensional/cloud-native formats are introduced.

## Scientific and safety boundaries

- all Chapter 7 records and coordinates are synthetic and cannot be presented as published field locations;
- SRID assignment is distinguished from coordinate transformation;
- `NULL` is never treated as measured zero;
- boundary ambiguity remains visible rather than being forced into one zone;
- database constraints are never presented as proof of sensor or field-measurement validity;
- learners use only disposable or explicitly authorised database environments and never store credentials in notebooks.
