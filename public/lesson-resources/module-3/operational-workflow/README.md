# Module 3 Chapter 7 — operational workflow training pack

This pack supports Lessons 3.26–3.30. All example identifiers, thresholds, monitoring results and schemas are synthetic teaching material. They are not measurements, locations or operational evidence from the published Baltic coastal-meadow dataset.

Use the templates to preserve a frozen feature meaning through raster inference, describe a bounded Earth Engine component, compare architectures, govern repeated predictions and assemble a model card. The neutral target label `target_units` prevents an undocumented unit from being implied.

The pack cannot support a real ecological accuracy, uncertainty, monitoring or deployment claim. Actual use requires approved target metadata, real protected validation, current platform documentation, spatial delivery QA, institutional data-governance review and an accountable release decision.

## Files

- `PREDICTION_SCHEMA_TEMPLATE.json`: ordered semantic feature contract
- `INFERENCE_RUN_TEMPLATE.json`: one raster inference run record
- `EARTH_ENGINE_COMPONENT_TEMPLATE.md`: image, sample, model and evidence contracts
- `ARCHITECTURE_DECISION_TEMPLATE.md`: local, Earth Engine and hybrid decision record
- `MONITORING_RUNBOOK_TEMPLATE.md`: repeated-prediction indicators and actions
- `MODEL_CARD_TEMPLATE.md`: evidence-led release documentation
- `TRAINING_DATA_SUMMARY_TEMPLATE.json`: machine-readable training provenance
- `monitoring_runs_fixture.csv`: synthetic monitoring-gate cases
- `manifest.json`: SHA-256 identity for this pack and the cumulative notebook

Never add credentials, private asset locations or sensitive field coordinates to a public submission.
