# Advanced Image Analysis training pack

This CC0-1.0 pack is entirely synthetic. It contains no real imagery, protected locations or operational model results. It exists to audit segmentation, spatial partitions, labels, regional error and applicability before ecological use.

Use `segmentation_tile.csv` as a 6 × 6 synthetic vegetation-index grid, `reference_labels.csv` as a deliberately simplified binary reference and `patch_partition_inventory.csv` to detect the deliberate train/test overlap condition. Complete `GEOSPATIAL_IMAGE_ANALYSIS_QA_TEMPLATE.md` before the Chapter 11 release decision.

Ecological context is informed by the Academy's Baltic coastal-meadow story. Do not attribute the numerical values or locations to Zenodo record 20083250.
